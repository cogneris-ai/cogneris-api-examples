# Cogneris Document AI SDK for Python

Generated client package for the public Cogneris Document AI API contract at
`openapi/cogneris-openapi.yaml`.

The distribution name is `cogneris-document-ai-sdk`, the import package is
`cogneris_document_ai_sdk`, and this source release is version `0.1.0`.

## Build

```shell
uv build
```

Do not edit generated client modules directly. Run `npm run generate:sdks` from
the repository root after changing the public OpenAPI contract or SDK config.
