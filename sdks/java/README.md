# Cogneris Document AI SDK for Java

Coordinates: `ai.cogneris:cogneris-document-ai-sdk:0.1.0`. Requires Java 17.

The typed client is generated from the repository's public OpenAPI contract.
Regenerate all SDKs from the repository root with `npm run generate:sdks`;
verify committed output with `npm run check:sdks`.

Build with the pinned Gradle wrapper from this directory using Java 17:

```sh
sh gradlew build
```

The POM supplies Maven package metadata; Gradle builds the JAR. Licensed under
Apache-2.0. The package root and JAR `META-INF/` directory include `LICENSE` and
`NOTICE`.
